# EMS 2.0 蓝湖更新需求

保存日期：2026-10-12（America/Los_Angeles）。基线 `e753be3`，目标 `2.0.13-lanhu`。

## 设计范围

本轮逐张读取同一蓝湖项目的全部60张画板。分类为29张当前页面/状态稿、17张旧对照稿、14张分组标题。不是60个独立功能页。保留56个运行路由，不新增重复状态菜单。

完整需求、逐页原稿/实际Qt截图、叠图、全部60张原稿及SHA256索引由 `tools/build-lanhu-update-review.py` 生成：

- `generated/lanhu-update/review/requirements.html`：可直接打开的图文需求文档。
- `generated/lanhu-update/review/requirements.md`：同内容Markdown。
- `generated/lanhu-update/review/inventory.json`：全部原稿来源、原始尺寸及SHA256。
- `generated/lanhu-update/review/evidence.json`：29个页面/状态对照关联和渲染SHA256。

上述路径相对仓库根。生成器中的 `REQUIREMENTS` 是逐页需求正文，`OLD_TO_NEW`、`TITLES` 明确覆盖全部60张画板，缺失任何一张会终止文档生成。

## 本次修改

1. 新版独立登录：原稿设备背景局部切图，品牌、真实账号/密码输入、登录与错误反馈由Qt原生控件渲染。没有整张页面截图覆盖控件。
2. 未登录拦截：公共导航、白色正文、登录提示和去登录按钮。只构建公共框架，不在遮罩下实例化受保护控件。
3. 公共页登录成功仍留在原页；从受保护页登录成功进入原目标。取消不能获得权限。
4. 登录状态在公共页同样显示退出。退出或会话过期销毁受保护视图；当前受保护页回到拦截，不改变保护范围。
5. 触摸键盘按需打开，支持账号/密码切换、大小写、退格和既有常用符号，保留物理键盘输入。
6. 原稿“记住密码”位置保留但禁用，提示未接入安全存储；不将密码写入文件、日志或配置。返回和键盘入口为实际使用补充。

## 约束与接口

- 只维护Gateway-zk；不修改EMS算法、SHM ABI、驱动及设备协议。
- 监测只读；保护前缀保持 `Guide-`、`Vehicle-`、`Strategy-`、`Control-`。
- 缺值、坏质量、过期、非有限数据均不得表示为正常；未知显示 `--`，预留控制禁用。
- 设计示例中的时间、正常状态和数值不能作为运行数据。
- PCS控制沿用确认、范围校验和真实回执；模式/并离网命令未经确认不得猜枚举。
- 策略运行点不等于使能点；当前只确认458防逆流使能可写。
- 单体电压保留mV，无功电能保留kvarh，消防减光率保留%，不为贴图而改变数据含义。
- 待补接口：独立从车成员及通信、柴油机、EMU主机资源、有线/GPS/IP、Pack归属、安全检查/部署、告警历史计数与发生/恢复时间、厂家命令枚举、安全凭据存储。
- 新接口需确认来源、数据类型、单位、缩放、刷新与过期、质量、读写属性、命令范围、权限、确认和回执。

## 验收

1. 56路由、画布边界、导航、真实点位、监测只读、预留动作及包校验通过；旧XMind34路由回归通过。
2. 原生测试覆盖错误密码、锁定、清空密码、键盘输入、取消、未登录拦截、登录后进入受保护页、退出及超时撤权。
3. 原稿统一映射到1440×810，登录另检查800×600等比缩放。真实终端分辨率与触摸可用性仍需真机测试。
4. 逐页视觉评分：分区与坐标35%、字体间距20%、图标颜色20%、控件状态15%、交互10%；已接入完整页面目标不低于95分。不得将大面积白底相同像素当作95%通过。
5. 当前未完成正式视觉评分。多车离线及部署安全状态尚缺接口，不能标为完整场景验收通过。
6. Allwinner AArch64须在192.168.22.11显式同步并核对固定源码后构建；真机字体、触摸、缩放、CPU/内存、启动和切页性能待验证。
