# EMS 2.0 蓝湖复核与单机拓扑修订

保存日期：2026-10-20（America/Los_Angeles）

## 范围与版本

- 本轮针对用户指出的“单机拓扑这些都有了”，继续核对已有完整设计，不因画板数量相同而停止实现。
- 当前蓝湖项目为 `be19aa1e-6480-4ca0-95a1-5ec773b5bd3e`，可访问的 39 张画板资源标识与 10 月 16 日记录一致：31 张完整页面/状态/备选稿、8 张分组标题。这只说明本次可读取资源未变，不等同于蓝湖中不存在其他更新。
- 单机拓扑此前已在本地候选实现；22.6 尚未部署此候选。此前实机无信号处理只重置显示输出，没有更新程序。
- 产品分支为 `realese1.0`，基线为 `aac6e5e1636f82df3a98b084653ffc977af7f25c`。本轮保留上一轮全部未提交修改，没有提交、推送或部署。
- 完整页面需求及数据约束继续遵循 [10 月 16 日逐页矩阵](lanhu-update-20261016.md)，本文件仅记录本轮增量与验证。

## 本轮修改

| 需求 | 实现 | 验证方式 |
| --- | --- | --- |
| 单机拓扑数值列贴合蓝湖 | 调整负荷、电源与 PCS 总功率/无功/功率因数列和分隔线位置；调整各相字段间距 | 固定坐标回归及原生截图 |
| 标题带与稿件一致 | 负荷、电源、PCS、电池组标题带保留顶部圆角，底部保持直线 | 生成器断言及截图 |
| 数字避免过粗 | 单机拓扑数值使用常规字重，保留长值适配行为 | 字重断言及缺值/超长值渲染 |
| 设备图片清晰 | 电表、PCS、电池图直接从 1920×1081 原始稿裁切，不先降采样到 1440×810 | 源图与输出 SHA256、尺寸核验 |
| 未知 PCS 状态保持中性 | 明确灰色背景和 `--`，避免透明色落为黑底；不改变并网/离网反馈判定 | 生成器回归及六种状态测试 |
| PCS 直流区完整 | 补直流电压与功率之间的分隔线 | 生成器断言及截图 |
| 评审可追溯 | 更新 39 张画板与原生截图对照；报告日期和需求链接可配置，交互测试失败时拒绝生成通过报告 | 证据索引及失败拒绝测试 |

本轮没有改 C++。先前候选中的登录背景、锁定页面、导航、PCS/TMS/BMS 监测、MCCB/柴油机操作图标等更新仍保留在当前候选中，不能误认为这些已在 22.6 生效。

## 数据与安全约束

- 单机拓扑继续分别读取负荷电表、电源电表、PCS、BMS 和三个独立断路器反馈；没有新增写命令。
- AC 母线独立采样、DC 接触器和功率方向没有已确认映射，保持未知或中性，不填设计示例值、不伪造能流。
- 并机拓扑继续按实际成员数量与离线状态显示，并保留分页；不把本机读数复制到其他车。
- 未确认的柴油机控制、策略使能、第二电池簇等接口继续预留；没有完整稿的页面继续留空。
- 设备协议、采集索引、SHM ABI、权限逻辑、开机自启和 kiosk 配置均未变化。预览包使用隔离测试凭据，不能直接作为现场发布包。
