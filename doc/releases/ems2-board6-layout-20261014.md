# 22.6 EMS 2.0 版式修正

日期：2026-10-14（America/Los_Angeles），设备日志为 2026-10-15。

## 范围与原因

- 用户报告 PCS、BMS 及其他页面错位，顶部文字看起来被拉长。
- 静态 `qtLabel` 不进入动态刷新列表，原先只在刷新时执行的 `qtAutoFit` 对静态标题不生效。BMS 长标题因此超出小面板。
- 原适配只检查单行宽度，没有检查文本高度，也没有逐行测量显式换行。
- PCS 底部统计字段超出面板；部分监测字段的标签与数值区域重叠 1px；柴油机参数的标签与数值区域相交。
- 原生 Qt 实测场景横纵缩放均为 1.333333，Xrandr 变换矩阵为单位阵，不能把字体观感问题直接归因于全屏非等比缩放。实际使用 Noto Sans CJK SC，不是缺少中文字体。

## 修改

1. 静态标签在首次绘制前适配，动态值更新时使用相同的逐行宽度和整体高度检查。
2. 保留显式换行和完整文本提示；长值变短后恢复允许的字号。只改变字号，不拉伸字形，字距为 0。
3. 顶栏标题与分隔线留出明确间距；复用现有高清登录 Logo，按图片原始比例居中显示。
4. 调整 PCS、BMS 和公共监测字段的上下间距、容器底部边界、表格列内边距，以及柴油机参数排列。
5. 保留 56 页原有路由和空白设计页。未新增采集点、伪造值、控制能力或账号。
