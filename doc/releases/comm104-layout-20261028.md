# COMM202600104 EMS 2.0 field alignment

## Scope and cause

- Display-only change authorized by the user; only `ky-ems.service` restarted.
- Titleless borderless status text retained a legacy 12-design-pixel inset on each side, unlike native labels and values. At 1920x1080 the left offset was 16 physical pixels.
- Monitor field captions and feedback mixed left and center alignment. Inline states now use their full text rectangle, and stacked field groups share center alignment.
- EMU icon fields, energy icon tiles and cell summary icon fields keep their intentional left alignment. Framed status cards keep their padding.
- Inline state labels opt into existing text auto-fit. No value conversion, point binding, state rule, widget action, permission or runtime configuration changed.
