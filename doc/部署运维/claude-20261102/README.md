## 原文校对说明

原文第 3 节“任何情况都不自动重发”范围过宽，不能解释成整个系统所有路径都禁止重发。这里保留原始导出，不静默改写；实际运维需结合以下说明和仓库发布记录：

- 本地画面不会自动重发。普通 AGC 未知事务不因零死区或遥测超时而重发。
- 已使能但不可用 PCS 的尽力安全归零保留原有例外，可能重发未知的 0；这不同于写入失败失效时未知 0 不重发的规则。
- 未知事务结算以后，零死区下已确认目标的正常周期刷新仍可能发送新命令，不是未知结果重试。
- 细节以 [控制确认发布说明](../../releases/control-confirmation-ems2-20261101.md) 的 AGC 规则和第 8.5 节为依据；[精简运维要点](../realese1.0控制确认运维要点-20261102.md) 已按此收窄表述。
