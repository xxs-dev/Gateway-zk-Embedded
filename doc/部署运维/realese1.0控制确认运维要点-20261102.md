## 1. 三条规则

1. 只有“反馈确认”才算动作确认。
2. “结果未知”既不是成功也不是失败：设备可能已经执行。
3. 本地画面不自动重发；控制仍经边端仲裁，本轮没有增加绕过仲裁的下发方式。不要将画面规则扩大成 AGC/AVC 的所有路径：已使能但不可用 PCS 的尽力安全归零仍可能重发未知的 0；已确认值的周期刷新也不属于未知结果重试。详见发布说明第 4 节。

## 2. 本地画面回执

| 回执 | 画面显示 | 算确认 | 该点的锁 |
| --- | --- | --- | --- |
| 还没有回执 | 命令已受理，等待驱动回执 | 否 | 保持 |
| `writeback-submitted` | 已下发，未确认 | 否 | 解除 |
| `writeback-succeeded`，未回读确认 | 协议写入成功，动作未确认 | 否 | 解除 |
| `verifyPassed=true` | 反馈确认成功 | **是** | 解除 |
| 本地参数或信箱已提交 | 本地参数已提交（未下发设备） | — | 解除 |
| 结果未知（超时、反馈不一致） | 结果未知：设备可能已执行；未自动重发 | 否 | **保持到跟踪期结束** |
| 确定失败 | 执行失败 + 阶段 + 原因 | — | 解除 |
| 10 秒仍无回执 | 等待回执超时，结果未知；继续跟踪到 70 秒，晚到的最终回执标为“晚到回执” | 否 | 保持 |

锁登记在进程级事务表里：退出登录、登录过期、工程重载都不解锁，重新登录后仍有效；到 70 秒跟踪期一律解锁，不留永久锁。KY-SCADA 进程重启后锁不保留。

## 3. 现场操作

1. 下发后看回执框。“已下发，未确认”“协议写入成功，动作未确认”都要到现场核实。
2. 出现“结果未知”**不要重复点击**。该点锁定到确定回执或 70 秒，期间点击会提示上一条命令编号。先核实实际状态，再决定是否重新操作。
3. PCS 三相汇总逐类列出各相结果，“3 相已下发、未确认”不等于功率已到位。
4. 灰色按钮可以点，只弹出不可用的原因，不下发。
5. 紧急操作用设备侧或独立急停回路，不依赖本画面；不要把重启 KY-SCADA 当作解锁手段。

## 4. 升级后的行为变化

| 方面 | 变化 | 要做什么 |
| --- | --- | --- |
| AGC/AVC | 结果未知时不再自动重发同一设定值，零死区和遥测超时也不例外；未知事务在晚到确定回执、遥测到达本事务目标或新设定值被受理时结束；AGC/AVC 服务重启后不保留 | 以前靠重发补偿丢包的现场，升级后连续失败计数会上升、按 `maxConsecutiveWriteFailures` 进入失效，需要人工核实 PCS 实际功率和通信，不要改配置去恢复自动重发 |
| confirmedControlWrite | 未确认但可能已执行时状态由 -1 改为 -2；CAN/DO 可用 `write.verifyIndex` 辅助反馈确认；不满足确认条件时下发前拒绝 | 自建图形 EMS 逻辑若读这个输出，要把 -2 也当作需要人工复位 |
| 画面状态 | 单一来源的未定义枚举显示“未知(原值)”；组合状态无效、陈旧、坏质量仍显示 `--` | 告知值班人员；“未知(原值)”先核对设备手册和点表 |
| 画面标签 | PCS 模式标签改为“模式设定”；PCS 监测页“控制模式”改为“PCS远程/就地”；电芯页共用探头只显示一次 | 告知值班人员 |
| SOE | 选中行改为浅蓝底深色文字 | 无 |
| 生成器 | 断路器槽位固定按 zh-CN 排序（并网、储能、负荷） | 只在重新生成时体现；已发布工程包不受影响 |
| 构建 | 新增 `local_display_qt_control_receipt.cpp`；22.11 Qt 测试 3 个变 5 个；Windows 预览补 SOE 依赖 | Windows 构建未验证 |

## 5. 104 现场工程

通用 56 页生成器不能替代 104 现场工程。重新生成时用现场运行配置（`-RuntimeConfigDirectory`），显式传入 BAU（`-BauMeterCode`），标准生成后再运行 `prepare_comm104_hgm6110nc_controls.py`；不得丢掉现场工程已有的绑定，未确认的电表口径不猜测补齐。

## 6. 常见现象

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 点击后提示上一条命令编号 | 上一条结果未知，该点在跟踪期内锁定 | 等确定回执或 70 秒；先核实现场 |
| 回执框改显示“晚到回执” | 10 秒内没收到，70 秒内收到了最终回执 | 按晚到结果处理 |
| AGC/AVC 进入写入失败失效 | 结果未知不再重发 | 人工核实 PCS 和通信 |
| confirmedControlWrite 输出 -2 | 结果未知、反馈不一致、只写入未确认，或没配确认条件被拒 | 核实设备后人工复位；检查 `verifyIndex` 或回读配置 |
| `SOE storage unavailable: min-free-bytes` | SOE 存储所在文件系统空闲低于生产保护要求的 256 MiB | 清理或扩容；不要调低保护阈值 |

其他排障仍按 [边端操作手册](边端操作手册.md) 第 13 节。
