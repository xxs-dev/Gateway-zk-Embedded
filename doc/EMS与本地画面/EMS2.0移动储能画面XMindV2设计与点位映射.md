# EMS 2.0 移动储能画面 XMind V2 设计与点位映射

## 1. 依据与范围

本文对应《移动储能画面_V2》XMind，适用于移动储能柜和移动储能车 EMS 2.0，不修改非移动储能柜 EMS 1.0。

XMind 同时包含目标功能树、2.0.9 历史页面说明和采集点附录。实现时按以下优先级处理：

1. 目标功能树决定一级入口、二级页面和信息分组。
2. 2.0.9 历史说明提供已验证的真实 Tag 绑定，不决定新布局。
3. 采集点附录用于查找真实点位；找不到的功能显示“未配置点位”，禁止借用其他语义点伪装。
4. 原有控制确认、可写校验、共享内存路由、本地登录和一小时趋势约束继续保留。

当前包版本为 `2.0.10-xmind-v2`，共 34 个 `1920x1080` 页面。目标屏幕为 10.1 寸横屏，默认入口为公开的 `Meters-Overview`，避免设备启动后立即弹出操作登录。

## 2. 为什么这样设计

XMind 的一级结构代表现场人员的工作顺序，而不是技术模块边界：

| 工作阶段 | 页面入口 | 设计原因 |
| --- | --- | --- |
| 投运前 | 引导 | 集中完成接入、部署和启动检查，避免在多个设备页来回查状态 |
| 日常值守 | 仪表、拓扑 | 先看关键指标和潮流，再进入分相明细 |
| 车辆作业 | 车辆 | 灯光和车辆状态独立，避免与柜内 DI/DO 混淆 |
| 趋势分析 | 曲线 | 所有趋势默认最近 1 小时，符合 10.1 寸现场短时诊断用途 |
| 异常处理 | 信息 | 设备告警和运行消息分开，不把通讯延迟当设备告警 |
| 专业操作 | 维护 | 设备、策略、PCS、DI/DO 和工程诊断统一归口 |

页面拆分的目标不是增加层级，而是保证一个页面只回答一个问题。分相数据使用固定矩阵；现场总览不放大表；缺少真实点位时明确暴露配置缺口。

## 3. 一级导航与权限

| 一级入口 | 默认路由 | 权限 | 内容 |
| --- | --- | --- | --- |
| 引导 | `Guide-Setup` | 登录 | 功能设置、设备部署、启动流程 |
| 仪表 | `Meters-Overview` | 公开 | 总览、电气、功率、能量 |
| 拓扑 | `Topology` | 公开 | 设备拓扑、功率、潮流、策略、断路器、4G |
| 车辆 | `Vehicle-Control` | 登录 | 场地灯、示廓灯和车辆固定状态 |
| 曲线 | `Trends-Power` | 公开 | 功率、电压、电流、功率因数、直流、电芯、自定义 |
| 信息 | `Info-Alarms` | 公开 | 活动告警、运行消息和状态 |
| 维护 | `Maintenance` | 公开入口 | 设备监测、策略监测、PCS 控制、DI/DO 控制、工程诊断 |

受保护前缀固定为：

```text
Guide-
Vehicle-
Strategy-
Control-
```

任何 `writeSetpoint`、`pulse`、`toggle` 或 `pcsPhasePowerControl` 控件位于公开页时，生成器直接失败。

## 5. 仪表点位映射

### 5.1 输出、输入、PCS 和穿越

| XMind 角色 | 设备/数据源 | 主要 index |
| --- | --- | --- |
| 输出监测 | 并网侧电表 `MTR20250600664` | 电压 `1030..1032`、电流 `1033..1035`、功率 `1036..1051`、频率 `1052`、相角 `1065..1070` |
| 输入监测 | 储能侧电表 `MTR20250600663` | 电压 `1130..1132`、电流 `1133..1135`、功率 `1136..1151`、频率 `1152`、相角 `1165..1170` |
| PCS 监测 | PCS `MTR20250600657` | 电压 `1220..1222`、电流 `1223..1225`、频率 `1226`、功率 `1227..1242` |
| 穿越监测 | 负荷电表 `COMM202600104_LOAD_METER` | 功率 `9036..9051` |

XMind 的功率参数要求“功率角”，当前点表只有功率因数，没有可直接绑定的功率角，也没有经过验收的计算点。因此功率页保留“功率角”位置并显示“未配置点位”；真实功率因数在 `Trends-Factor` 展示，不能把功率因数改名冒充功率角。

### 5.2 能量参数

| 内容 | index | 说明 |
| --- | --- | --- |
| SOC / SOH | `1569 / 1570` | BMS 实时值 |
| 可充 / 可放电量 | `1590 / 1591` | 用作当前剩余能量，不伪造剩余时间 |
| 最近一次充 / 放电量 | `1588 / 1589` | XMind 的“本次充放电” |
| 今日充 / 放电量 | `1615 / 1616` | 当日累计 |
| 累计充 / 放电量 | `1586 / 1587` | 当前协议高位累计值 |
| 移动储能 2 | 无 | 当前工程未接入，页面显示“未接入” |
| 柴油发电机 | 无 | 当前工程未接入，油量和剩余时间不生成假数据 |

## 6. 拓扑与控制绑定

拓扑使用并网功率 `1039`、储能侧功率 `1139`、PCS 功率 `1230`、负荷功率 `9039`、SOC `1569` 和真实断路器 DI。能量流控件仅根据绑定功率方向和死区播放动画。

PCS 三相功率控制必须使用：

| 控制量 | index |
| --- | --- |
| A/B/C 相有功 | `1318 / 1319 / 1320` |
| A/B/C 相无功 | `1321 / 1322 / 1323` |

`1328..1333` 属于一次调频、并离网开关模式和电池允许值，不得再作为分相功率绑定。

DI/DO 页继续按运行时点表动态发现风机、指示灯、急停、浪涌、水浸、柜门和断路器。场地灯、示廓灯只有在工程提供同名可写点时才生成真实按钮。

## 7. 当前明确缺少的点位

COMM202600104 当前基线没有以下点位：

| XMind 功能 | 当前处理 |
| --- | --- |
| 主从机自动连接状态 | 显示“未配置点位” |
| 柴油机接入方式、油量、剩余时间 | 显示“未接入” |
| 车辆制动、支撑、GPS | 显示“未配置点位” |
| 车辆接地电阻 | 显示“未配置点位”，不使用 BMS 绝缘值替代 |
| 场地灯、示廓灯 | 显示“未配置点位”，不使用运行灯/放电灯替代 |
| PCS 电气相角和平均值 | 显示“未配置点位” |
| 功率角 | 显示“未配置点位” |
| 第二套移动储能 | 显示“未接入” |

后续只需在项目运行时点表中补充语义明确的点位并重新生成工程，页面会按名称发现车辆和灯光点；其他新增点应先补语义映射再接画面。

## 8. 曲线规则

- 所有 `qtChart` 的 `chartDefaultWindowMinutes=60`。
- 功率、电压、电流和功率因数按 XMind 分页，避免在 10.1 寸屏上叠加过多单位。
- 直流页拆成 SOC、电压、电流、功率四个图；电芯页拆成电压极值和温度极值两个图。
- 自定义页当前是工程预设对比，不提供现场任意改绑；动态选点属于组态编辑器能力，不在边端运行画面直接修改工程。
