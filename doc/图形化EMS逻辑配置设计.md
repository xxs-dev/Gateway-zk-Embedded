# 图形化 EMS 逻辑配置设计（兼容入口）

当前完整设计统一维护在 [EMS与本地画面/图形化EMS逻辑配置设计.md](EMS与本地画面/图形化EMS逻辑配置设计.md)。V2 唯一制品和生产执行边界见 [EMS与本地画面/EMS逻辑编辑器V2单文件直执行说明.md](EMS与本地画面/EMS逻辑编辑器V2单文件直执行说明.md)。

现行约束：

- Windows、平台和边端使用同一份 `schemaVersion=2.x` 策略文件。
- 生产 `ComputeEngine` 不执行 `legacyEms`，也不提供 V1 回退开关。
- V1 只允许由 Windows 原路径迁移，或由 `EmsParityCheck` 和回归测试作为离线基线读取。
- 舜通 2026-07-26 迁移细节见 [EMS与本地画面/舜通20260726策略迁移说明.md](EMS与本地画面/舜通20260726策略迁移说明.md)。
