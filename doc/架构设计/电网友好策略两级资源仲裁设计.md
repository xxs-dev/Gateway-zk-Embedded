# 电网友好策略两级资源仲裁设计

## 1. 目标

电网友好策略不能把“满足电网目标”简单等同于“让电池充放电”。统一执行顺序为：

1. 先使用不消耗电池净能量或不依赖电池的一级资源。
2. 一级资源不足时，只让储能承担剩余量。
3. 输出请求量、一级调节量、储能兜底量、实际量、未满足量和限制原因。
4. 安全闭锁、SOC、设备能力、视在功率和写回校验仍是最终约束，策略不能绕过。

该顺序统一的是资源仲裁原则，不是把所有策略套进同一个公式。

## 2. 各策略的一级资源

| 策略 | 一级调节 | 二级调节 | 说明 |
| --- | --- | --- | --- |
| 柔性三相平衡 | PCS 三相之间零净能量搬移 | 电池净充放电补残差 | 一级结果三相合计为 0 kW |
| 功率因数、AVC | 无功 Q | 视在功率仍不足时裁剪有功 P | `reactivePowerFirst` 必须落实到单台 PCS，而不只在站级生效 |
| 电压治理 | Volt-VAR 无功 | Volt-Watt 有功 | 必须配置明确的 Volt-VAR/Volt-Watt 曲线；旧图只有有功电压补偿时，不视为已具备完整 Volt-VAR |
| 防逆流、动态增容、削峰、AGC | 光伏逆变器、柔性负荷等非电池资源 | 储能 PCS | 现场没有一级执行器时，一级调节量自然为 0，不能虚构能力 |
| 光伏优先充电 | 可利用光伏余量 | 电池吸收剩余光伏 | 电池仍受 SOC、允许充电功率和 PCS 能力约束 |

## 3. 统一符号

- 有功正值：向交流侧送电、放电。
- 有功负值：从交流侧吸收、充电。
- 无功方向由项目的 `reactiveSignConvention` 定义。
- 厂家寄存器方向差异由执行器映射或 `commandSign` 转换，算法内部不使用厂家符号。

## 4. AGC/AVC 配置

### 4.1 资源层级

`agcAvc.activeResourcePriority`：

- `nonBatteryFirst`：先分配一级非电池资源，再把残差分配给储能，推荐值。
- `capacityWeighted`：兼容旧项目，所有可用设备按能力和权重共同分配。

每台设备可通过 `pcs[].activeResourceTier` 显式指定：

- `primary` 或 `nonBattery`：一级资源。
- `battery`：储能资源。
- `auto`：`storagePcs`、`batteryPcs` 归入储能，其余类型归入一级资源。

### 4.2 P/Q 优先级

`agcAvc.pqPriority` 支持：

- `reactivePowerFirst`：先分配 Q，再使用剩余视在功率分配 P。
- `activePowerFirst`：先分配 P，再使用剩余视在功率分配 Q。
- `proportional`：P/Q 同比例缩放。

分配顺序在站级和单台 PCS 两层都必须一致。

## 5. Graph EMS 末级约束

`powerConstraint` 新增 `pqPriority`，默认保持原行为 `reactivePowerFirst`。节点可选输出：

- `requestedActiveTotalOutputIndex`
- `requestedReactiveTotalOutputIndex`
- `deliveredActiveTotalOutputIndex`
- `deliveredReactiveTotalOutputIndex`
- `unservedActiveTotalOutputIndex`
- `unservedReactiveTotalOutputIndex`
- `limitationFlagsOutputIndex`
- `unservedActiveOutputIndexes[]`
- `unservedReactiveOutputIndexes[]`

舜通模块化 EMS 使用稳定 Index `690001-690007` 输出总量诊断。

## 6. 限制原因位

### 6.1 AGC/AVC `720065`

| 位 | 数值 | 含义 |
| --- | ---: | --- |
| 0 | 1 | 一级资源不足或不可用 |
| 1 | 2 | 已使用储能兜底 |
| 2 | 4 | 有功目标未完全满足 |
| 3 | 8 | 无功目标未完全满足 |

### 6.2 Graph EMS `690007`

| 位 | 数值 | 含义 |
| --- | ---: | --- |
| 0 | 1 | 有功被限制 |
| 1 | 2 | 无功被限制 |
| 2 | 4 | P/Q 视在功率圆限制 |
| 3 | 8 | 站级总有功限制 |
| 4 | 16 | SOC 或状态闭锁 |
| 5 | 32 | 动态增容储备介入 |

## 7. 运行边界

- AGC/AVC 仍是独立运行模式和独立附加包，不进入通用初始化包。
- Graph EMS、AGC/AVC、MQTT 人工控制必须共用功率控制权仲裁，禁止双写。
- 未配置非电池执行器的老项目不会因升级自动获得一级资源，只会增加正确的诊断输出。
- 柔性三相平衡新节点必须在影子模式验证后再替换现场策略。

## 8. 验收

1. 一级能力足够时，电池调节量必须为 0。
2. 一级能力不足时，电池调节量必须等于目标残差，不得重复承担一级已经完成的部分。
3. 充电和放电方向均执行相同优先级。
4. `reactivePowerFirst` 下，单台 PCS 超出能力圆时保持 Q、裁剪 P。
5. SOC、允许充放电、设备离线和急停触发后，实际输出不得越过闭锁。
6. 请求量必须等于实际量与未满足量的代数或逐相差值，限制原因位与实际限幅一致。
